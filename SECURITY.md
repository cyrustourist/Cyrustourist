Security Policy

Supported Versions

CyrusTourist is actively developed and security fixes are applied to the latest available version of the project.

Version| Supported
Latest| :white_check_mark:
Older versions| :x:

Reporting a Vulnerability

If you discover a security vulnerability in CyrusTourist, please report it privately rather than opening a public GitHub issue.

Please use GitHub's private vulnerability reporting feature, when available, to submit the report securely.

When reporting a vulnerability, please provide:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The potential security impact
- Any relevant screenshots, logs, or proof-of-concept information

Please do not publicly disclose the vulnerability before it has been reviewed and, where appropriate, fixed.

We will review security reports and take reasonable steps to investigate and address confirmed vulnerabilities.
